## Reproduction

1. `py scripts/build_address_evidence.py --download` refreshes official municipal/ANNCSU files; omit the flag to use the cached snapshot.
2. `py scripts/fetch_bdtre_torino.py` acquires/extracts the advertised Torino package if missing.
3. `py scripts/build_bdtre_evidence.py` adds conservative BDTRE access candidates to the local crosswalk. Run after rebuilding address evidence, which replaces that read model.
4. `py scripts/fetch_property_inventory.py --capped-parcels --limit 30` queries the next not-yet-cached parcel batch. Existing response files are retained; failed responses currently require explicit local investigation rather than automatic retry.
5. `py scripts/build_property_registry.py` then `py scripts/build_registry_package.py` regenerate source models/export, preserving review events. Start/restart the local review service after changing `scripts/serve_registry.py`.

Raw files stay in ignored `_raw/`; local address evidence is ignored `output/addresses/evidence.json`, accessible through the loopback review service only. ANNCSU redistribution terms have not been fully reviewed; the new crosswalk is not added to the publication allowlist. This phase does not broaden the publication allowlist or copy raw archives into Git history. Original data provider attribution remains applicable.
